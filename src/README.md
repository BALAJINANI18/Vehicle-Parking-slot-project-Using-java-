# 🚗 Parking Slot Management System

A beginner-friendly **Core Java project** that simulates a simple parking slot management system.

This project was created to practice basic Java programming and Object-Oriented Programming concepts.

## 📌 Features

* Park a vehicle
* Remove a vehicle
* View all parking slots
* Search for a vehicle
* Supports Cars and Bikes
* Automatically assigns the first available parking slot
* Shows the vehicle owner and parking slot

## 🛠️ Technologies Used

* Java
* Core Java
* Object-Oriented Programming

## 🧠 OOP Concepts Used

This project demonstrates basic OOP concepts:

* **Class**
* **Object**
* **Encapsulation**
* **Inheritance**
* **Abstraction**
* **Interface**

## 🚘 How It Works

The parking area contains **5 slots**.

Initially:

```text
Slot 1 : Empty
Slot 2 : Empty
Slot 3 : Empty
Slot 4 : Empty
Slot 5 : Empty
```

When a vehicle is parked, the program automatically finds the first available slot.

Example:

```text
Vehicle Number: TS09AB1234
Owner Name: Balaji
Vehicle Type: Car

Vehicle parked successfully!
Slot Number: 1
```

After parking:

```text
Slot 1 : TS09AB1234
Slot 2 : Empty
Slot 3 : Empty
Slot 4 : Empty
Slot 5 : Empty
```

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Open the project

Open `Main.java` in:

* IntelliJ IDEA
* Eclipse
* VS Code
* NetBeans

### 3. Compile

```bash
javac Main.java
```

### 4. Run

```bash
java Main
```
